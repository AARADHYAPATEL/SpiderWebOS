#SpiderOS

[Open SpiderOS](https://spideros.aaradhyap.hackclub.app)

I have made my own PERSONAL OS called SpiderOS. What I love about this OS is that it has many goofy and personal elements to me and I am might proud that I have built an actual functioning Web OS which works kind of like windows. What was very challenging was to get the SVG right and I did have to use AI to get the SVG right.

This OS first has a welcome screen that will tell you all about me, the creator of the OS. You can explore 2 more apps, one is thread book that is personalised to me, and the other is Between the Threads, which is an interactive and beautiful story of a spider. I’m sure you will love Between the Threads!

It also has a ticking timer, and it has all the features that have been listed by the guide, but there is 1 extra feature: A day and night toggle! Now you can save your eyes by this feature during the nighttime and not blow away your beauty sleep.

Thread book is an app that tells you all about me in a very nice way and it’s like my very own scrapbook! Between the Threads is the story of a spider that weaves its web depending on what choices you take.

The Welcome Screen can be accessed again by clicking on the SpiderOS text on the top. All 3 windows are draggable, closable and reopenable. Also, you open the apps by double clicking them, with a single click only highlighting them. There is also z-index prioritization so say if I have both Thread book and Welcome Screen window and Thread book is on top of Welcome Screen window, then I can just click on the Welcome Screen window, and it will come before thread book.

It has a very green theme to it as green is one of the most calming colours, actually it is the most calming colour and I wanted my OS to be calming, so that is why it has a lot of green elements to it.

It is deployed on Nest so that it can run 24/7 even when my laptop is turned off, so anyone can use it.

IT IS NOT PASSWORD PROTECTED!!

## Running locally

Clone the repository, then run:

```bash
npm install serve
npx serve -s . -l 3000

and then open http://localhost:3000 on your browser
